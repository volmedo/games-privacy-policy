# Política de privacidad de los juegos de Binary Tinkerers

Una sola política para todos los juegos que no recogen datos, servida con
GitHub Pages en `https://games.binarytinkerers.com` (fichero `CNAME`):

- `/privacidad/` en español y `/privacy/` en inglés.
- Al publicar un juego nuevo, se añade su nombre a la lista del principio.
  Si un juego trata datos de otra forma (analíticas, nube, cuentas), lleva
  su propio apartado.
- Google Play y la App Store piden el enlace en la ficha y dentro del juego.
- HTML estático sin dependencias, cookies ni analíticas.

Este repo es público y cada push publica: no pongas aquí nada que no deba
verse.
