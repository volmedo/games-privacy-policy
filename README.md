# Web de los juegos de Binary Tinkerers

Páginas públicas de los juegos (de momento, las políticas de privacidad que
pide Google Play), servidas con GitHub Pages en
`https://juegos.binarytinkerers.com` (fichero `CNAME`).

- Una carpeta por juego: `<juego>/privacidad/` (es) y `<juego>/privacy/` (en).
- HTML estático sin dependencias, cookies ni analíticas.
- La fuente de verdad del texto es esta web; `store/privacy.md` de cada
  juego apunta aquí.

Este repo es público: no pongas aquí nada que no deba verse.
